Entry for the [One Letter: Coffee or Tea](https://make.fun/bounty/u-rusdyxbt-one-letter-coffee-or-tea-89877fa0) bounty on make.fun.

The program writes exactly one letter to `/output/entry.txt`: **A** for coffee. Coffee wins the morning — dark, hot, and already working before the kettle has even boiled.

Run it with:

```sh
node main.ts
```
